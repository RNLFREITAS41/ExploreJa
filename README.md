Plataforma web para exploração e descoberta de destinos, desenvolvida como projeto técnico utilizando PHP, HTML, CSS, JavaScript e banco de dados.

1 - Instalar o Laragon/XAMPP.
2 - Colocar a pasta do projeto no www/htdocs.
3 - Criar/importar o banco de dados.
4 - Configurar as credenciais do banco, se necessário.
5 - Iniciar Apache + MySQL.
6 - Acessar pelo navegador.
